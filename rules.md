# Aurora Photo Editor

Производительный фоторедактор для операционной системы Аврора (Aurora OS), написанный на C++ и QML.

## 🏗 Архитектура

Проект строго разделен на два слоя:
1. **Frontend (QML + Sailfish Silica):** Отвечает исключительно за отрисовку интерфейса. Взаимодействует с бэкендом через сигналы и `Q_INVOKABLE` методы контроллера.
2. **Backend (C++ / Qt 5):** Вся бизнес-логика, обработка изображений (OpenCV) и машинное обучение (ONNX).

### Ключевые архитектурные решения:
* **Интеграция C++ и QML:** Отображение рабочего холста реализовано через кастомный `QQuickImageProvider` (`PipelineImageProvider`), зарегистрированный по протоколу `image://pipeline/`. Это позволяет без копирования передавать результат обработки в QML.
* **Многопоточность и Worker Pattern:** Запрещено блокировать UI-поток. Все эффекты (например, инференс нейросетей) выполняются в фоне. Для `PipelineManager` реализован строгий контроль жизненного цикла `QThread` (через указатель `m_activeWorker`) — если пользователь быстро меняет настройки (троттлинг), старый поток отменяется, а новый ставится в очередь, защищая систему от OOM.
* **Оптимизации производительности:**
  - Тяжелые операции вроде смешивания изображений распараллеливаются по ядрам CPU с помощью `QtConcurrent::blockingMap`.
  - Для эффектов вроде сильного Гауссова размытия (Blur) используется пайплайн с предварительным уменьшением картинки (`downscale -> cv::GaussianBlur -> upscale`), что ускоряет рендер в десятки раз без визуальной потери качества.
* **Управление памятью:** Отключено стандартное кэширование QML для динамических изображений (`cache: false`). Кэшируются только промежуточные результаты вычислений нейросети (например, маска сегментации `m_cachedMask`), чтобы избежать повторного инференса при изменении настроек фона.

## 🛠 Зависимости и Стек

* **ОС:** Aurora OS SDK (Qt 5.6)
* **Сборка:** CMake
* **Библиотеки:**
  * Qt 5 (Core, Network, Qml, Gui, Quick, Concurrent)
  * OpenCV (Обработка изображений, алгоритмы фильтрации)
  * ONNXRuntime (ML-инференс для умных фильтров, например U2NET)

## 📂 Структура проекта

* `src/` — C++ Backend, бизнес-логика и обработка изображений.
  * `main.cpp` — Точка входа, инициализация приложения и регистрация типов.
  * `PipelineManager` (.h/.cpp) — Центральный контроллер, управляет стэком команд (Undo/Redo), загрузкой/сохранением и контролирует активные фоновые потоки (`updateBackground`).
  * `BackgroundWorker` (.h/.cpp) — Асинхронное выполнение `ImageEditorCommand` в `QThread`.
  * `MLProfiler` (.h/.cpp) — Сборщик микросекундных таймингов фаз алгоритмов (выводит JSON логи).
  * `MLInferenceEngine` (.h/.cpp) — Движок работы с нейросетями (ONNXRuntime).
  * `MLTensorProcessor` (.h/.cpp) — Изолированная обработка, конвертация и нормализация тензоров для ML-моделей.
  * `ImageEditorCommand.h` — Абстрактный интерфейс для всех команд редактора.
  * `BackgroundCommand` (.h/.cpp) — Команда удаления и замены фона (поддерживает режимы: Цвет, Градиент, Размытие), включает многопоточный блендинг и кэширование масок.
  * `EnhanceCommand` (.h/.cpp) — Алгоритм авто-улучшения фото (CLAHE + Баланс белого).
  * `PipelineImageProvider.h` — Провайдер `image://pipeline/`.
* `qml/` — UI Frontend (QML + Sailfish Silica).
  * `pages/MainPage.qml` — Главный экран: холст для фото, верхнее меню и нижние выезжающие панели (`DockedPanel`) с настройками инструментов (цвет фона, градиент, интенсивность размытия).
  * `pages/AboutPage.qml` — Страница «О приложении».
  * `pages/NoticePage.qml` — Страница системных уведомлений (например, об успешном сохранении).
* `tests/` — Директория с юнит-тестами (QtTest).
* `rpm/` — Файлы конфигурации пакетирования (.spec).
* `translations/` — Файлы локализации (.ts).

## 🚀 Как начать работу

1. Откройте проект в Aurora IDE.
2. Убедитесь, что у вас настроены таргеты сборки для требуемой архитектуры (armv7hl / aarch64 / i486).
3. При необходимости подтяните зависимости OpenCV и ONNX (через pkg-config).
4. Нажмите Build & Run (Собрать и Запустить).
