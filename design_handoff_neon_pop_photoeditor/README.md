# Handoff: AuroraPhotoEditor UI — «Neon Pop»

## Overview
Дизайн-референс интерфейса для AuroraPhotoEditor — офлайн-редактора фото на Aurora OS (Qt5/QML + C++ + OpenCV + ONNX Runtime). Стиль «Neon Pop»: тёмный фон, неоновые фиолетово-розово-зелёные акценты, шрифты Unbounded (дисплей) + Manrope (текст). Полностью сохраняет функционал из `functional-spec-for-design.md` и добавляет фичи из `architectural_plan_onnx.pdf` (Слои 4–6: кастомный фон, ручная правка маски, превью стилей, пакетная обработка, сериализация проекта).

## About the design file
`Aurora Variant 1 Neon Pop.dc.html` — это **HTML/React-прототип для дизайн-ревью**, не продакшн-код. Он кликабельный (реальные переходы между состояниями), но вся «обработка фото» в нём симулирована через `setTimeout` — реального ONNX/OpenCV инференса там нет. Задача разработчика — **воссоздать эти экраны нативно на Sailfish Silica (QML)**, подключив реальный C++-бэкенд (`PipelineManager`, `MLInferenceEngine`, `BackgroundWorker`), а не встраивать HTML в приложение.

## Fidelity
**High-fidelity** по цветам/шрифтам/отступам/радиусам и по набору экранов/переходов. **Low-fidelity** по «содержимому» операций — там, где бэкенд ещё не реализован (Фон, Стиль, кисть/ластик, пакетная обработка), прототип показывает предполагаемый UI и таймаут-эмуляцию; разработчик подключает реальные вызовы по мере готовности слоёв 4–6 архитектурного плана.

## Целевое устройство
F+ T1100, 1600×2176 px, ~244 PPI, **theme_pixel_ratio = 1.25**. Все размеры ниже — уже итоговые CSS-px для этого экрана; при переносе в Silica используйте `Theme.pixelRatio`-множители, а не хардкодите px (см. Design Tokens).

## Screens / Views

### 1. MainPage — пусто (нет фото)
- `PageHeader`: заголовок «PhotoEditor» слева (Unbounded 800 44px), справа 2 иконки — Undo/Reset, обе **всегда видны, но disabled** (opacity 0.35) когда `canUndo=false`. Save скрыт (не рендерится) при `hasImage=false`. About — иконка круга-инфо, всегда активна.
- Под шапкой — тонкая полоса-аффорданс «⌄ Потянуть вниз — меню» (высота 56px), по тапу открывает `PullDownMenu`.
- Центр экрана: иконка изображения в квадрате 180×180 (radius 44, фон `#1f1830`), заголовок «Нет выбранного фото» (Unbounded 700 38px), подзаголовок (Manrope 500 28px, цвет `#b7a9d9`), кнопка-пилюля «Выбрать фото» (градиент `#8b5cf6→#ec4899`, высота 92px, radius 999, Unbounded 700 30px).

### 2. PullDownMenu
Три пункта (иконка 34px + текст Unbounded 700 30px, паддинг 24×40):
1. «Выбрать фото» → системный `ImagePickerPage` (Sailfish.Pickers) → `pipelineManager.loadFromUri(uri)`.
2. «История изменений» + бейдж количества шагов справа → открывает History-панель.
3. «Пакетная обработка» → новый экран Batch.

### 3. MainPage — фото загружено
- Холст фото: margin 28px со всех сторон, radius 32px, `PreserveAspectFit`. Подпись имени файла — плашка по центру (только пока в прототипе нет реального фото).
- Поверх холста при `isProcessing=true`: спиннер (кольцо 96px, обводка `rgba(255,255,255,.15)`, верхняя дуга `#22e5a0`, вращение 0.9s linear) + подпись текущей операции (Unbounded 700 30px).
- `DockedPanel` снизу (высота 180px, паддинг 24px, gap 20px, `open: hasImage`): 3 кнопки-квадрата radius 28 — «Фон» (иконка слоёв, `#8b5cf6`), «Улучшение» (иконка искры, `#22e5a0`), «Стиль» (иконка палитры, `#ec4899`). Все три — `opacity 0.4` и не кликабельны при `isProcessing`.
- Клик «Улучшение» → сразу запускает `EnhanceCommand` (без экрана параметров) — busy-оверлей ~1.1с (в реальном коде — до готовности CLAHE+Gray World), затем в стек добавляется шаг «Улучшение».

### 4. Bottom Sheet — «Фон»
Заголовок + close-крестик. Внутри:

## Interactions & Behavior
- **Переходы между экранами** — Sailfish `pageStack.push/pop` (About, Notice, Batch — это Page на стеке; MainPage — initialPage). Sheets/History/Toast/Mask-edit — не отдельные Page, а `DockedPanel`/`Dialog`/оверлей поверх MainPage.
- **Fade** между сменой фото — 400мс (по споке).
- **Disabled-состояния во время `isProcessing`**: тулбар (Фон/Улучшение/Стиль), Undo, Reset, Save — все неактивны. Если пользователь всё же тапает другой инструмент во время обработки — предыдущая операция считается отменённой, показывается toast «Предыдущая операция отменена» (сквозная механика, п.4 функционального ТЗ).
- **Debounce 450–500мс** на выбор стиля (не запускать тяжёлый инференс на каждый быстрый тап).
- **Кэширование маски** при работе с фоном: движение слайдера интенсивности/размытия не должно перезапускать ML-инференс, только Alpha Blending (см. Слой 4 архитектурного плана).
- **Undo** — откат на 1 шаг назад по стеку команд, доступен только для последнего шага. **Reset** — полная очистка стека, возврат к оригиналу.
- **Save** — JPEG q95 в `~/Pictures/AuroraPhotoEditor_<timestamp>.jpg`, без диалога выбора пути; по завершении — `NoticePage` (успех/ошибка).
- **Decompression bomb** (>64 Мп) — должен показываться Toast с ошибкой загрузки (в текущем бэкенде эта ветка молча ничего не делает — доработать).

## State Management
Ключевые реактивные свойства (маппятся на `PipelineManager`, доступный в QML как singleton context property):

| Прототип (DC state) | Реальный источник |
|---|---|
| `hasImage` | `pipelineManager.hasImage` |
| `canUndo` | `pipelineManager.canUndo` |
| `isProcessing` | `pipelineManager.isProcessing` |
| `steps[]` (стек шагов) | `commandCount()` + сериализация стека команд (сейчас не выведено в UI — этот дизайн выводит) |
| `screen` (empty/loaded/about/notice/cover/batch) | `pageStack` состояние + локальный enum на MainPage |
| `sheet` (bg/style/null) | локальное состояние MainPage (открыт ли DockedPanel/Dialog инструмента) |
| `maskEditMode` | локальный флаг + `QQuickPaintedItem` для кисти |
| `batchSelected[]`, `batchProgress` | новый `BatchWorker` (ISSUE-6.4), сигналы прогресса в UI |

Изображение — через `image://pipeline/current?t=<timestamp>` (см. функциональный ТЗ п.3.3) — таймстемп обязателен, иначе Qt закэширует старую картинку.

## Design Tokens

**Цвета**
- Фон: `#15101f` (базовый), `#1a1428` (шапка/поверхности), `#1f1830` / `#241b38` (карточки/чипы)
- Текст: `#f5f1ff` (первичный), `#b7a9d9` (вторичный), `#8b7aa8` / `#6d5c8f` (третичный/подписи)
- Акценты: фиолетовый `#8b5cf6`, розовый `#ec4899`, зелёный `#22e5a0`
- Ошибка: `#e2265f` / успех: `#22c583`
- Основной градиент действия: `linear-gradient(135deg,#8b5cf6,#ec4899)`

**Типографика** (Unbounded — дисплей/заголовки/кнопки, Manrope — текст/подписи)
- H1 заголовок экрана: Unbounded 800 40–44px
- Заголовок карточки/пусто-состояния: Unbounded 700 36–38px
- Кнопка: Unbounded 700 28–32px
- Тело/подписи: Manrope 500–600 24–30px
- Мелкие подписи/хинты: Manrope 500 22px

**Отступы/радиусы** (кратны `theme_pixel_ratio=1.25`, база 10px = 8×1.25)
- Паддинги: 10 / 20 / 24 / 28 / 32 / 40 px
- Радиусы: чипы/кнопки — 16–24px, крупные карточки/sheets — 32–44px, пилюли — 999px
- Высота хедера: 140px; докнутая панель инструментов: 180px; иконка-кнопка: 72×72px; крупная CTA-кнопка: 88–96px
- Минимальный размер тач-таргета — 64px, у большинства кнопок 72–96px (комфортно для планшета)

**Прочее**
- Иконки — тонкая обводка 2–2.4px, `stroke-linecap/linejoin: round`, без заливки (кроме акцентных точек)
- Тени практически не используются (плоский стиль) — только один слой мягкой тени под модальными sheets

## Assets
- Все иконки в прототипе — инлайн SVG-заглушки (простые линии). **Не продакшн-ассеты** — нужно заменить на нативный иконостиль Aurora/Silica или предоставленный дизайнером SVG-набор.
- Фото-плейсхолдер — полосатый CSS-паттерн с подписью `photo.jpg`. Реальные фото не включены — placeholder до интеграции.
- Шрифты — Google Fonts Unbounded + Manrope, подключены через `<link>` в прототипе; для Aurora нужно упаковать `.ttf`/`.otf` и подключить через `FontLoader` в QML (лицензии Google Fonts позволяют локальное встраивание).
