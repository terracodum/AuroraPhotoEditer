# Aurora Photo Editor

Производительный фоторедактор для операционной системы Аврора (Aurora OS), написанный на C++ и QML.

## 🏗 Архитектура

Проект строго разделен на два слоя:
1. **Frontend (QML + Sailfish Silica):** Отвечает исключительно за отрисовку интерфейса. Не содержит тяжелой логики.
2. **Backend (C++ / Qt 5):** Вся бизнес-логика, обработка изображений и работа с файловой системой.

### Ключевые архитектурные решения:
* **Интеграция C++ и QML:** Отображение рабочего холста реализовано через кастомный `QQuickImageProvider` (класс `PipelineImageProvider`), зарегистрированный по протоколу `image://pipeline/`. Это позволяет моментально передавать пиксели из C++ в QML.
* **Многопоточность (Worker Pattern):** Запрещено блокировать UI-поток (главный поток). Любые тяжелые операции (например, экспорт и сохранение изображений) вынесены в фоновые потоки (`QThread`) через паттерн `Worker`.
* **Управление памятью:** Отключено стандартное кэширование QML для динамических изображений (`cache: false`), чтобы предотвратить OOM (утечки памяти) при многократном наложении фильтров. История изменений (Undo/Redo) безопасно хранится на стороне C++ в `PipelineManager`.
* **Профилирование ML (Таймеры):** Все операции обработки изображений (`ImageEditorCommand`), особенно инференс ONNX, обязаны фиксировать время выполнения своих внутренних фаз (препроцессинг, инференс, постпроцессинг) через передаваемый объект `MLProfiler`. Сбор микросекундных таймингов и вывод структурированного JSON-лога осуществляется централизованно в `BackgroundWorker`.

## 🛠 Зависимости и Стек

* **ОС:** Aurora OS SDK (Qt 5.6)
* **Сборка:** CMake
* **Библиотеки:**
  * Qt 5 (Core, Network, Qml, Gui, Quick, Concurrent)
  * OpenCV (Обработка изображений)
  * ONNXRuntime (ML-инференс для умных фильтров)

## 📂 Структура проекта

* `src/` — C++ логика (`PipelineManager`, Worker-классы, `main.cpp`).
* `qml/` — UI интерфейс (страницы, каверы, диалоги).
* `rpm/` — Файлы для сборки установочного пакета (.spec).
* `translations/` — Файлы локализации (.ts).

## 🚀 Как начать работу

1. Откройте проект в Aurora IDE.
2. Убедитесь, что у вас настроены таргеты сборки для требуемой архитектуры (armv7hl / aarch64 / i486).
3. При необходимости подтяните зависимости OpenCV и ONNX (через pkg-config).
4. Нажмите Build & Run (Собрать и Запустить).
